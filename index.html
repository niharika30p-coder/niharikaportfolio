Featured project

Academic project · Cybersecurity

SENTINEL: Intrusion Detection and Prevention using Suricata

A cybersecurity project designed to collect and display Suricata IDS/IPS security events through a web-based SOC dashboard.

SuricataUbuntu ServerPythonFastAPIReact / Next.jsTailwind CSSWebSocketsGemini API
  • Reads and processes Suricata eve.json events.
  • Displays security alerts in a dashboard.
  • Includes event filtering and severity indicators.
  • Provides a threat-map visualization.
  • Supports AI-assisted alert explanations and remediation suggestions.
  • Supports investigation of suspicious activity, including port scans and brute-force attempts.
View on GitHub

How it works

  1. Suricata inspects network traffic on an Ubuntu Server and writes events to eve.json.
  2. A Python / FastAPI backend reads those events and streams them over WebSockets.
  3. A web dashboard shows alerts with filters, severity levels and a threat map.
  4. The Gemini API adds plain-language explanations and suggested fixes for each alert.

What I set out to learn

  • How an IDS/IPS detects suspicious traffic.
  • How to read and interpret Suricata alerts and logs.
  • How port scans and brute-force attempts appear in event data.
  • How a SOC analyst might view and triage alerts.
  • How to connect a backend and a dashboard in one working system.
